- Associated research article: Paige and Perreault (2024), DOI: 10.1073/pnas.2319175121.

The file is included for transparent reproduction. Users must preserve attribution and consult the upstream archive for the authoritative version.

## ROAD

The manuscript discusses the ROCEEH Out of Africa Database (ROAD), but no live ROAD database export is bundled here. Any future ROAD-derived dataset must document the query date, variables, filtering, database version and applicable terms.
